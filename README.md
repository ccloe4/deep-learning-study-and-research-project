# Research Project

## Overview
This repository contains my deep learning study and experiments using PyTorch.

## Environment
- OS: Ubuntu 22.04 (WSL2)
- Python: 3.10
- Framework: PyTorch
- GPU: RTX 3070

## Directory Structure

- data/: datasets (ignored)
- configs/: experiment configurations
- models/: model definitions
- src/: training & evaluation logic
- notebooks/: exploratory notebooks
- scripts/: run scripts
- logs/: experiment outputs
